# Music Director — Compatibility Pointer

This repository is packaged as a portable skill. Start at `SKILL.md`; the complete
orchestration rules are in `instructions/orchestration.md`.

This file is only a compatibility pointer for tools that auto-load `AGENTS.md`.

Fundamental principle: musical knowledge informs creative judgment; it does not
replace it. Conventions, genres, examples and established patterns are references,
not mandatory recipes. See `instructions/orchestration.md`, "Core principles"
("Fundamental principle: musical knowledge without creative formulas") for the
canonical statement and its application across the project.
