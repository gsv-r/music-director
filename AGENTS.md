# Music Director: compatibility pointer

This repository is packaged as a portable skill. `SKILL.md` is the entry point.
The rules that govern the work are in `references/instructions/orchestration.md`.

This file exists for tools that load `AGENTS.md` automatically. It adds no rules
of its own.

Musical knowledge guides the decisions here, but each composition still calls
for its own judgment. A genre or a convention describes what is common. It does
not decide what one particular song must do. Two songs in the same genre can end
up with different structures, arrangements and performances. The canonical
statement is in `references/instructions/orchestration.md`, under "Core
principles", in "Fundamental principle: musical knowledge without creative
formulas".

What the project provides is criteria, vocabulary, methods, questions and
checks. You will not find ready-made lyrics, a finished style line, a filled
tag, a structure or a development arc to copy. Examples are limited to single
terms and lacunae like `[<section> - <audible change from this song>]`. The
material comes from the user: a brief, an image, lyrics, references or intent.
