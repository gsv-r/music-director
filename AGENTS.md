# Music Director: compatibility pointer

This repository is packaged as a portable skill. Start at `SKILL.md`; the complete
orchestration rules are in `references/instructions/orchestration.md`.

This file is only a compatibility pointer for tools that auto-load `AGENTS.md`.

Fundamental principle: musical knowledge informs creative judgment; it does not
replace it. Conventions, genres, examples and established patterns are references,
not mandatory recipes. See `references/instructions/orchestration.md`, "Core principles"
("Fundamental principle: musical knowledge without creative formulas") for the
canonical statement and its application across the project.

The project supplies tools, not a ready-made base: criteria, vocabulary, methods,
questions and checks, rather than material to copy as a default. No lyrics, full
Style line, filled tag, structure or development arc is provided. Examples are
limited to isolated terms and lacuna formats (e.g., `[<section> - <audible change
from this song>]`). The starting material comes from the user's context (brief,
image, lyrics, references, intent).

Final composition deliveries follow the fixed four-field format in
`references/instructions/orchestration.md`, "Final delivery format (mandatory)":
`[LYRICS]`, `[STYLE]`, `[TITLE]` and `[ANALYSIS]`, in that order, each in its own
code block. Arrangement, development, performance direction and technical analysis
remain part of the creative process and are translated into those fields.
